本页说明模板中 Markdown 的推荐写法。为了同时兼容网页和打印输出，内容应尽量使用标准 Markdown。

## 推荐结构

1. 使用导航中的页面名称作为标题。
2. 正文从一段说明开始。
3. 使用二级和三级标题组织小节。
4. 代码块标注语言。
5. 行内公式使用 `$...$`，块级公式使用 `$$...$$`。

## 添加文章

在 `docs/` 下创建 Markdown 文件，然后登记到 `mkdocs.yml`：

```yaml
nav:
  - 首页: index.md
  - 新文章: new-page.md
```

## 页面功能

- 顶部导航用于切换主题页面。
- 左侧导航显示站点结构。
- 右侧目录跟随当前文章。
- 右上角搜索框使用本地生成的搜索索引。
- 浅色和深色模式跟随系统，也可以手动切换。

网页构建不会修改 Markdown 源文件。打印转换需要单独执行上游 `OI-Wiki-export` 工具。
